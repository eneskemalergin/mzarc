- Optimized encode runs: 1.5441s, 1.5262s, 1.5242s

Per-block activation summary from `--verbose-blocks`:
- 72/72 blocks used m/z rANS
- 72/72 blocks used intensity split-exponent+rANS
- Average m/z rANS gain: 28.58% per block
- Average intensity rANS gain over split-exponent base: 6.42% per block
- Intensity gain range: 1.32% to 8.15%

Interpretation:
- The encoder-side waste was real and fixable: encode time improved by ~35.6% (2.3780s -> 1.5315s).
- Decode time barely moved (0.7514s -> 0.7403s). The remaining bottleneck is not bad activation decisions; it is the cost of decoding rANS on every block, especially for the m/z stream where every block still clears the gain gate by a wide margin.
- Decision for Part 3a.4: defer. The entropy path is still not fast enough on 15HCD_1 to justify adding more payload/layout complexity.
