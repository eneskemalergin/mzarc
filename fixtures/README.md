# fixtures/

This directory contains the frozen test fixture used by `zig build ci` and `zig build check-fixture`.

## frozen.bin

A deterministically sliced 1,000-spectrum subset of `data/PXD075509/15HCD_1.bin`, generated by `tools/slice_fixture.py`.

### Composition constraints

| Constraint                       | Required      | Actual |
| -------------------------------- | ------------- | ------ |
| Total spectra                    | exactly 1,000 | 1,000  |
| MS1 spectra                      | ≥ 100         | 110    |
| MS2 spectra                      | ≥ 800         | 890    |
| Distinct isolation windows (MS2) | ≥ 3           | 430    |
| Sparse spectra (< 5 peaks)       | ≥ 10          | 10     |
| Dense spectra (> 1,000 peaks)    | ≥ 5           | 46     |
| Empty spectra (0 peaks)          | ≥ 1           | 1      |

Sparse and empty spectra are fabricated deterministically (`random.seed(42)`) because
the source dump (min 16 peaks/spectrum) contains no such spectra naturally.

## Adversarial corpus (test/adversarial/)

The adversarial corpus is generated by `tools/gen_adversarial.py` (added in v0.2.0 task 1.3).
See the task checklist for the full category list. Each `.bin` file exercises a specific codec edge case
that real mzML data does not trigger.
